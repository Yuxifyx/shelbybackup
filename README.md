# ShelbyBackup

Decentralized backup DApp built on [Shelby Protocol](https://shelby.xyz).

## Features
- Upload & backup files to Shelby decentralized network
- Connect with Petra wallet (Aptos)
- Real-time job queue with progress tracking
- Automated backup schedules
- AES-256 encryption via wallet key
- Fully responsive — desktop & mobile

## Tech Stack
- React 18 + TypeScript + Vite
- @shelby-protocol/sdk
- @aptos-labs/wallet-adapter-react
- Geomi API — Aptos node provider

## Network
- **Network:** Shelbynet (Testnet)
- **Shelby RPC:** https://api.shelbynet.shelby.xyz/shelby
- **Aptos Node:** https://api.shelbynet.shelby.xyz/v1
